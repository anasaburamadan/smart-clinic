# Smart Clinic Appointment and Patient Management System

A responsive graduation project for managing clinic appointments, patients, doctors, consultations, prescriptions, laboratory requests, invoices, reports, and role-based dashboards.

## Demo roles

- Patient
- Doctor
- Receptionist
- Lab Technician
- Administrator

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The ready-to-publish static website is included in the `docs` folder.
